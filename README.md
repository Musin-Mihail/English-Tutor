# English Tutor AI

**English Tutor AI** — веб-приложение для практики перевода с русского на английский с помощью ИИ. Система выступает в роли репетитора: даёт задания, проверяет переводы (включая голосовые ответы), объясняет грамматические ошибки, ведёт журнал обучения и отслеживает успеваемость по темам.

Прогресс хранится в локальной базе SQLite — история обучения не зависит от облака.

## Основные возможности

- **Генерация заданий:** ИИ анализирует успеваемость и формирует новые предложения для перевода, делая упор на слабые темы.
- **Умная проверка:** Cursor SDK для разбора перевода + локальный Whisper (буквальный режим) и wav2vec2 CTC для произношения.
- **Озвучка эталона:** после проверки Kokoro произносит правильный английский вариант.
- **Детальный фидбек:** объяснение ошибок грамматики и произношения, правильные варианты, альтернативы и рекомендации.
- **Таблица успеваемости:** автоматический пересчёт среднего балла по грамматическим темам.
- **Многовкладочный интерфейс:** «Практика», «Успеваемость», «Журнал занятий».
- **Аудио-журнал:** прослушивание прошлых голосовых ответов и разбор ошибок.
- **Трекинг затрат:** счётчик токенов сессии (стоимость Cursor — в дашборде).

## Установка и запуск

Нужен **Python 3.10+**. Для распознавания речи на GPU рекомендуется **NVIDIA CUDA** (например, RTX 5090 с 24 ГБ VRAM — модель `large-v3` загружается без проблем).

### 1. Установите зависимости

Из **корня проекта**:

```bash
pip install -r requirements.txt
```

При желании можно использовать venv — это необязательный шаг для изоляции пакетов.

### 2. Настройте окружение

Скопируйте пример конфигурации и укажите ключ API:

```bash
# Windows (PowerShell)
Copy-Item .env.example .env

# macOS / Linux
cp .env.example .env
```

Откройте `.env` в корне проекта:

```env
AI_PROVIDER=cursor
CURSOR_API_KEY=your_cursor_api_key_here
CURSOR_MODEL=composer-2.5

# Локальное распознавание речи на GPU
WHISPER_MODEL=large-v3
ASR_DEVICE=auto
ASR_COMPUTE_TYPE=auto

# Акустический проход и озвучка правильного варианта
ACOUSTIC_ASR=true
TTS_ENABLED=true
TTS_VOICE=af_heart
```

Ключ Cursor: [Dashboard → Integrations](https://cursor.com/dashboard/integrations).

**Прокси:** если нужен прокси (например, для legacy-провайдера Gemini), раскомментируйте `PROXY_URL` в `.env`. Настройки подхватываются в `run.py` до запуска приложения.

### 3. Запустите приложение

Из **корня проекта**:

```bash
python run.py
```

Откройте в браузере: [http://localhost:8000](http://localhost:8000)

При первом запуске автоматически создаётся база данных в `app/data/`. При старте сервера подгружаются Whisper, wav2vec2 и Kokoro (первый раз скачиваются веса — несколько минут).

## Провайдеры ИИ

Переключение через `AI_PROVIDER` в `.env`:

| Провайдер               | Переменная       | Описание                                    |
| ----------------------- | ---------------- | ------------------------------------------- |
| `cursor` (по умолчанию) | `CURSOR_API_KEY` | Cursor SDK, локальный агент в `cwd` проекта |
| `gemini`                | `GOOGLE_API_KEY` | Google Gemini (нативная загрузка аудио)     |

### Как используется GPU

- **Whisper (ASR):** `faster-whisper` с `ASR_DEVICE=auto` автоматически выбирает CUDA. На RTX 5090 рекомендуется `WHISPER_MODEL=large-v3` и `ASR_COMPUTE_TYPE=float16`. Декодирование буквальное (`ASR_BEAM_SIZE=1`, без сглаживания по предыдущему тексту), чтобы модель меньше «додумывала» правильный английский.
- **wav2vec2 CTC:** второй проход без сильного языкового модели — ближе к тому, что реально сказано. Если PyTorch CUDA недоступен, работает на CPU.
- **Kokoro TTS:** озвучка `correct_variant` на CPU (модель ~300 МБ), видеокарту не занимает.
- **Cursor SDK:** локальный агент (`local=LocalAgentOptions`) — разбор грамматики и оценка идут через Cursor API.

## Использование

1. Откройте [http://localhost:8000](http://localhost:8000).
2. ИИ предложит задание на русском языке (5 предложений).
3. Запишите перевод каждого предложения через микрофон.
4. Нажмите «Отправить на проверку».
5. Получите оценку, разбор ошибок и рекомендации; прослушайте правильный вариант в колонке справа. Следующее задание учитывает ваши слабые темы.
