# English Tutor AI

**English Tutor AI** — веб-приложение для практики перевода с русского на английский с помощью ИИ. Система выступает в роли репетитора: даёт задания, проверяет переводы (включая голосовые ответы), объясняет грамматические ошибки, ведёт журнал обучения и отслеживает успеваемость по темам.

Прогресс хранится в локальной базе SQLite — история обучения не зависит от облака.

## Основные возможности

- **Генерация заданий:** ИИ анализирует успеваемость и формирует новые предложения для перевода, делая упор на слабые темы.
- **Умная проверка:** Google Gemini для распознавания речи, проверки перевода и оценки от 0 до 10.
- **Детальный фидбек:** объяснение ошибок, правильные варианты, альтернативы и рекомендации.
- **Таблица успеваемости:** автоматический пересчёт среднего балла по грамматическим темам.
- **Многовкладочный интерфейс:** «Практика», «Успеваемость», «Журнал занятий».
- **Аудио-журнал:** прослушивание прошлых голосовых ответов и разбор ошибок.
- **Трекинг затрат:** счётчик токенов и оценка стоимости сессии API.

## Установка и запуск

Нужен **Python 3.10+**. Виртуальное окружение (`venv`) **не обязательно** — зависимости можно установить в глобальный Python или в любое окружение, которое вы уже используете.

### 1. Установите зависимости

Из **корня проекта**:

```bash
pip install -r requirements.txt
```

При желании можно использовать venv — это необязательный шаг для изоляции пакетов, не требование проекта.

### 2. Настройте окружение

Скопируйте пример конфигурации и укажите ключ API:

```bash
# Windows (PowerShell)
Copy-Item .env.example .env

# macOS / Linux
cp .env.example .env
```

Откройте `.env` в корне проекта:

```env
GOOGLE_API_KEY=your_google_api_key_here
```

**Прокси:** если Google API недоступен в вашем регионе, раскомментируйте и задайте `PROXY_URL` (например, `http://127.0.0.1:12334`). Настройки подхватываются в `run.py` до запуска приложения.

### 3. Запустите приложение

Из **корня проекта**:

```bash
python run.py
```

Откройте в браузере: [http://localhost:8000](http://localhost:8000)

При первом запуске автоматически создаётся база данных в `app/data/`.

## Использование

1. Откройте [http://localhost:8000](http://localhost:8000).
2. ИИ предложит задание на русском языке (5 предложений).
3. Запишите перевод каждого предложения через микрофон.
4. Нажмите «Отправить на проверку».
5. Получите оценку, разбор ошибок и рекомендации; следующее задание учитывает ваши слабые темы.

## Переход с Gemini API на Cursor

Сейчас логика ИИ сосредоточена в `app/services/grader_agent.py`: класс `GraderAgent` вызывает Google Gemini через SDK `google-genai` (генерация заданий и проверка аудио).

Переход на **Cursor** (Cursor SDK / Cloud Agents API) возможен и укладывается в ту же архитектуру без переписывания UI и базы данных.

### Что остаётся без изменений

- Gradio-интерфейс (`app/ui.py`)
- SQLite и журнал (`app/data/database.py`)
- Контекст для ИИ (таблица успеваемости + история занятий)

### Что нужно заменить

| Сейчас (Gemini)                            | При переходе на Cursor                                                                        |
| ------------------------------------------ | --------------------------------------------------------------------------------------------- |
| `GOOGLE_API_KEY`                           | `CURSOR_API_KEY` (ключ из настроек Cursor)                                                    |
| `google.genai.Client`                      | `cursor-sdk` (`pip install cursor-sdk`)                                                       |
| `client.aio.models.generate_content(...)`  | `Agent.prompt(...)` или `Agent.create()` + `agent.send(...)`                                  |
| Загрузка аудио через `client.files.upload` | Передача путей к файлам в промпт или отдельный шаг распознавания (зависит от модели и режима) |

### Рекомендуемый план миграции

1. **Ввести абстракцию провайдера** — интерфейс с методами `generate_new_task()` и `grade_translation()`, реализованный сейчас в `GraderAgent`.
2. **Добавить `CursorGraderAgent`** — реализация через Cursor SDK:

   ```python
   from cursor_sdk import Agent, AgentOptions, LocalAgentOptions

   result = Agent.prompt(
       prompt_with_context_and_audio_paths,
       AgentOptions(
           api_key=os.environ["CURSOR_API_KEY"],
           model="composer-2.5",
           local=LocalAgentOptions(cwd=str(PROJECT_ROOT)),
       ),
   )
   ```

3. **Выбор провайдера через `.env`** — например, `AI_PROVIDER=gemini` или `AI_PROVIDER=cursor`, инициализация в `app/core/deps.py`.
4. **Сохранить формат JSON-ответа** — промпт в `MASTER_PROMPT_TEXT` и парсинг (`_clean_json_response`) можно оставить; Cursor-агент должен возвращать тот же JSON для совместимости с UI и БД.

### Ограничения и отличия

- **Аудио:** Gemini нативно принимает аудиофайлы в `generate_content`. Cursor SDK ориентирован на агенты в репозитории; для голосовых ответов может потребоваться отдельный ASR (или модель с поддержкой мультимодальности в выбранном режиме).
- **Стоимость и лимиты:** тарификация и квоты Cursor отличаются от Google AI — блок токенов в UI нужно пересчитать под новый провайдер.
- **Прокси:** настройки `PROXY_URL` в `run.py` актуальны для Gemini; для Cursor Cloud Agents запросы идут на API Cursor, поведение прокси может отличаться.
- **Локальный vs облачный режим:** Cursor SDK поддерживает `local` (агент в `cwd` проекта) и cloud (VM Cursor). Для этого приложения обычно достаточно `local` с `cwd=PROJECT_ROOT`.

Документация Cursor SDK: [Python](https://cursor.com/docs/sdk/python), [TypeScript](https://cursor.com/docs/sdk/typescript).
