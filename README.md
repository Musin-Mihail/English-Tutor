# English Tutor AI

**English Tutor AI** — это веб-приложение для практики перевода с русского на английский язык с использованием искусственного интеллекта. Система выступает в роли репетитора: дает задания, проверяет переводы, объясняет грамматические ошибки, ведет журнал обучения и отслеживает успеваемость по конкретным темам.

Особенностью проекта является **хранение прогресса в локальной базе данных**, что позволяет отслеживать историю обучения.

## ✨ Основные возможности

- **Генерация заданий:** AI анализирует вашу успеваемость и генерирует новые предложения для перевода, делая упор на темы, в которых у вас пробелы.
- **Умная проверка:** Использование модели Google Gemini (Gemma) для проверки перевода, поиска ошибок и оценки от 0 до 10.
- **Детальный фидбек:** Объяснение ошибок, правильные варианты перевода, альтернативы и рекомендации.
- **Таблица успеваемости:** Автоматический пересчет среднего балла по грамматическим темам.
- **Многовкладочный интерфейс:** Удобное разделение на "Практику", "Успеваемость" и "Журнал занятий".
- **Аудио-журнал:** Возможность прослушивать прошлые голосовые ответы и анализировать ошибки.
- **Трекинг затрат:** Встроенный счетчик использованных токенов и расчет стоимости сессии API.

## 🛠 Технический стек

### Backend (Серверная часть)

- **Python**
- **FastAPI** — веб-фреймворк.
- **Google Generative AI** — API для доступа к LLM моделям (Gemma/Gemini).
- **Pydantic** — валидация данных.
- **SQLite** — база данных для хранения истории.

### UI / Клиентская часть

- **Gradio** — библиотека веб-интерфейсов для Python.

## 🚀 Установка и запуск

Для работы проекта требуется установленный **Python**.

### 1. Запуск

1. Перейдите в папку `backend`:

```bash
cd backend
```

2. Создайте виртуальное окружение (рекомендуется):

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. **Настройка окружения (.env):**
   В папке `backend` переименуйте файл-пример `.env.example` в `.env`:

- Откройте `.env` и вставьте ваш ключ `GOOGLE_API_KEY`.
- **Прокси:** Если вы находитесь в регионе, где Google API заблокирован (например, РФ), раскомментируйте и настройте переменную `PROXY_URL` (например, `http://127.0.0.1:12334`). Код в `run.py` автоматически подхватит эти настройки.

5. Запустите сервер:

```bash
python run.py
```

Сервер запустится на `http://0.0.0.0:8000` (в браузере открывать `http://localhost:8000`).

> **Примечание:** При первом запуске приложение **автоматически создаст** базу данных SQLite в папке `app/data/`.

## 📂 Структура данных

Прогресс студента хранится в папке `backend/app/data/`.
_Эти файлы игнорируются git'ом, чтобы сохранить вашу приватность. При первом старте создается БД SQLite._

- **`tutor.db`**: База данных SQLite, содержащая журнал заданий, пути к аудио и историю успеваемости.
- **`audio_records/`**: Папка для хранения ваших сохраненных голосовых ответов.

## 🖥 Использование

1. Откройте браузер на `http://localhost:8000`.
2. AI-учитель предложит вам задание на русском языке.
3. Введите перевод в поле ввода и нажмите `Ctrl+Enter` или кнопку отправки.
4. Дождитесь проверки. Вы увидите:

- Вашу оценку (x/10).
- Правильный вариант.
- Список ошибок с объяснениями.
- Рекомендации.

5. Нажмите "Отправить на проверку" еще раз, чтобы получить следующее задание, сформированное на основе ваших ошибок.
